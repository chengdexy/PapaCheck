TinySchedule

一款面向 10-14 岁儿童的每日学习计划管理工具。挂墙大屏展示任务进度，积分激励培养时间管理习惯，爸爸手机管理端轻松布置与评级。

🖥️ 大屏端 📱 管理端 🔊 语音提醒 ⭐ 积分系统 🏪 积分商店 🛡️ 局域网运行

🏠 使用场景

一个家庭，两块屏幕，一套系统

🖥️ 孩子大屏端 — 挂墙平板，查看作业、挑战计时、积分商店

📱 爸爸管理端 — 手机浏览器访问，布置作业、评级、配置

⭐ 核心功能

覆盖作业全生命周期的完整功能闭环

📝

作业布置与管理

爸爸用手机布置每日作业，设置科目、建议时长和基础分。支持驳回重做，灵活应对各种情况。

⏱️

挑战 & 计时双模式

挑战模式显示倒计时和进度条，提前完成获效率奖励；计时模式记录实际用时，超时自动降级。

🔊

语音提醒

挑战开始、时间过半、还剩 5 分钟、还剩 1 分钟、超时警告——全程语音陪伴，超时后每 30 分钟重复提醒。

⭐

积分激励系统

完成作业获得基础分，提前完成获效率奖励。爸爸评优/良/可/差，加倍系数累乘最终积分。

🏪

积分商店 & 奖励箱

孩子用积分兑换商品：游戏时间、实物奖励、Buff 增益。两步兑换流程防止误操作。

✨

Buff 增益系统

支持限时 Buff（持续 N 分钟）和每日 Buff（持续 N 天），如「晚睡 30 分钟」，到期自动消失。

📊

数据统计 & 趋势

爸爸端查看近 7 天完成率、效率比趋势、评级历史，清晰掌握孩子学习状态。

🖥️

大屏屏保 & 整点报时

60 秒无操作进入大数字时钟屏保，整点语音报时。点击任意位置唤醒，语音确认。

从布置到结算，一气呵成

1

两步确认，防止误操作

2

🛠️ 技术架构

极简部署，零依赖构建

组件技术
前端纯 HTML + CSS + JavaScript，无框架，无构建工具
后端Python 3 标准库 http.server
数据库SQLite（单文件 data.db）
语音合成edge-tts（微软 Edge TTS，zh-CN-XiaoxiaoNeural）
通信局域网 HTTP REST API，每 5 秒轮询同步
部署单命令 `python server.py` 启动，局域网所有设备可访问
存储零云端依赖，全部数据存在本地 SQLite

🔌 API 接口

14 个 REST 端点，覆盖完整业务

端点说明
GET /api/data获取全量数据
GET /api/speak?text=...TTS 语音合成，返回 MP3 音频
GET/POST /api/homeworks/:date作业 CRUD
GET/POST /api/settlement/:date结算数据 CRUD
POST /api/points积分增减（earn/spend/adjust）
GET/POST /api/shop商店商品管理
GET/POST /api/redemptions兑换券管理
GET/POST /api/reward-box奖励箱管理
GET/POST /api/settings系统参数配置
GET/POST /api/active-buffsBuff 管理
GET/POST /api/freetime/:date自由时间任务
POST /api/reset-date重置当天数据

🚀 快速开始

Python 3 环境，一条命令启动

python server.py

大屏访问地址：http://localhost:8080
管理端地址：http://localhost:8080/admin.html
局域网内手机访问：http://<电脑 IP>:8080/admin.html
