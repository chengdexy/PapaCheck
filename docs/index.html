使用指南

三步搞定全家使用

不需要懂编程，跟着步骤走就能让全家用起来

1

下载并启动服务端

在家庭电脑上下载 Windows 版（或运行 Python 服务端），启动后自动创建数据库，零配置即可运行

2

配置邮件同步（可选）

在管理端填入老师和自己的邮箱信息，AI 自动拉取作业邮件并解析入库，以后都不用手动添加作业

3

孩子用手机打开大屏端

孩子在手机/平板浏览器上打开链接，即可看到作业清单，开始挑战模式赚积分，在商店兑换奖励

📌 整套系统在家庭局域网内运行，数据不经过云端，无需注册账号，用完即走
