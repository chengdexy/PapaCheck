使用流程

三步开启家庭作业新方式

01

启动服务端

一行命令启动 Python HTTP 服务器，自动创建数据库和 TTS 缓存，零配置运行

cd PapaCheck.Server && python server.py
02

配置邮件同步

填写 IMAP 邮箱信息，AI 自动拉取老师布置的作业邮件，解析内容并录入清单

03

全平台使用

孩子用手机/平板打开 Web 大屏端开始做作业，家长用管理端远程评级，Windows 桌面端可选
