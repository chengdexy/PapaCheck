快速开始

三步搞定全家使用

不需要懂编程，跟着步骤走就能让全家用起来

1

下载并启动 Windows 桌面端

从 GitHub Releases 下载最新版 PapaCheck.exe，双击运行即可。服务默认启动在 8080 端口，首次运行自动创建数据库和 TTS 语音缓存

2

浏览器访问（任何设备）

在手机/平板浏览器输入 EXE 主界面上显示的局域网地址（192.x.x.x:8080），孩子端和管理端均可从同一入口访问

3

邮件同步（可选）

在 Windows 端菜单栏选择服务配置，填写 IMAP 邮箱信息和 API Key。点击邮件作业同步，AI 自动拉取邮件、解析作业并发布

📌

整套系统在家庭局域网内运行，数据不经过云端，无需注册账号
