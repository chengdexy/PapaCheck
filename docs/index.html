使用指南

三步搞定全家使用

不需要懂编程，跟着步骤走就能让全家用起来

1

运行 PapaCheck.exe

在家庭电脑上下载并运行 Windows 桌面版，GUI 自动启动内置服务器，首次运行自动创建数据库，零配置即可使用

2

其他设备浏览器访问

在手机/平板浏览器输入 EXE 主界面上显示的局域网地址（192.x.x.x:8080），孩子端和管理端均可从同一入口访问

3

Android 设备安装 APK

在 Android 设备浏览器访问 /api/download 下载安装 APK，或从管理端页面扫码安装，即可获得原生应用体验

📌 整套系统在家庭局域网内运行，数据不经过云端，无需注册账号，用完即走
