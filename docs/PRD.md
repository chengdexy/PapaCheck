# PapaCheck 产品需求文档（PRD）

> 最后更新：2026-06-03 | 版本：1.1.5

## 一、产品概述

### 产品名称

PapaCheck（爸~检查！）

### 一句话定位

面向家庭局域网的家长辅助工具，帮助家长管理和跟踪孩子的作业完成情况。

### 核心价值

将"催作业"从亲子冲突转化为游戏化激励——孩子自主完成作业获得积分，家长远程评级管理，用正向反馈替代监督压力。

### 目标用户

| 角色 | 场景 |
|------|------|
| 家长（主要用户） | 远程查看作业进度、评级、管理积分商店、发布赏金任务 |
| 孩子（核心用户） | 自主开始/暂停/完成作业、查看积分、兑换奖励、领取赏金 |

### 运行环境

- **部署模式**：一台电脑做服务器 + 多设备浏览器/APP 访问（局域网）
- **客户端**：Web 浏览器（孩子端大屏 + 管理端）、Android APP、Windows 桌面端

---

## 二、核心业务流程

```
老师邮件布置作业 → AI 自动解析并添加到清单
                              ↓
孩子自主开始/暂停/完成作业 → 计时器记录用时
                              ↓
家长远程评级（优/良/可/差） → 结合效率加成计算积分
                              ↓
积分兑换商店奖励 / 赏金任务 / 奖励箱 → 形成激励闭环
```

## 三、功能清单

### 3.1 作业管理（MVP 核心）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 添加作业 | 家长手动添加作业（名称、科目、预计时间） | P0 |
| 作业计时 | 孩子开始/暂停/完成作业，计时器实时记录 | P0 |
| 挑战模式 | 限时完成作业，超时语音提醒 | P1 |
| 自由模式 | 不限时，纯计时器记录 | P1 |
| 进度展示 | 进度条和动画反馈 | P1 |
| 邮件同步 | 微信群转发老师作业到指定邮箱，AI 自动解析并发布 | P1 |
| 附件下载 | 邮件中的图片/文件自动下载保存 | P2 |
| 在校提前完成 | 孩子端一键标记已在学校完成，记录用时和建议时长的90% | P1 |

### 3.2 积分与评级（MVP 核心）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 家长评级 | 优/良/可/差 四级评级 | P0 |
| 积分计算 | 评级 × 效率加成 = 最终积分 | P0 |
| 积分历史 | 查看积分获取和消费记录 | P1 |
| 效率统计 | 按日期查看效率比（覆盖所有非驳回已完成作业） | P2 |

### 3.3 积分商店

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 商品管理 | 家长添加/编辑/下架商品 | P1 |
| 积分兑换 | 孩子用积分兑换游戏时间或奖励物品 | P1 |
| Buff 系统 | 兑换后获得加成效果（如双倍积分） | P2 |
| 兑换记录 | 查看历史兑换 | P2 |

### 3.4 奖励箱与赏金任务

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 奖励箱 | 家长发放奖励，孩子自主兑换 | P2 |
| 赏金任务 | 家长发布任务（如"帮妈妈洗碗"），孩子完成后获积分 | P2 |
| 赏金提交 | 孩子提交完成证明 | P2 |
| 赏金审核 | 家长确认完成并发放积分 | P2 |

### 3.5 语音提醒（TTS）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 任务超时提醒 | 挑战模式超时时语音提醒 | P1 |
| 评级结果播报 | 评级完成后语音播报结果 | P2 |
| 商店上新提醒 | 新商品上架时语音提醒 | P2 |

### 3.6 数据统计

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 作业用时图表 | 折线图展示每日作业用时 | P2 |
| 评级分布 | 饼图展示评级分布 | P2 |
| 效率比趋势 | 折线图展示效率比变化 | P2 |

### 3.7 多端支持

| 功能 | 描述 | 优先级 |
|------|------|--------|
| Web 孩子端 | 大屏展示，适合平板/电脑 | P0 |
| Web 管理端 | 家长管理界面 | P0 |
| Android APP | Flutter WebView 混合应用 | P1 |
| Windows 桌面端 | 系统托盘 + 开机自启 + 配置管理 | P1 |
| 离线支持 | Service Worker + localforage 缓存 | P1 |
| 增量同步 | 基于 last_modified 的数据同步 | P1 |
| APK 自动更新 | 检测服务器版本，提示下载安装 | P2 |

## 四、非功能需求

| 需求 | 描述 |
|------|------|
| 局域网部署 | 零外部服务依赖，Python + SQLite 即可运行 |
| 离线优先 | 断网时核心功能可用，联网后自动同步 |
| 轻量级 | 单文件数据库，低资源占用，适合老旧电脑 |
| 安全存储 | Windows 端使用 Credential Manager 存储敏感凭据 |
| 开源 | GNU AGPL v3.0 |
