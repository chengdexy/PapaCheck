📅 PapaCheck 开发周报 — 6月第1周

💬 爸爸的话

这一周是 PapaCheck 历史上最疯狂的一周——超过 100 次提交。我们把整个服务器从 Python 换成了 Node.js，写了全新的数据同步引擎，修了数不清的 Bug。你可能看不出来有什么变化，但底下的东西几乎全换了一遍。就像给一辆跑着的车换发动机。

🆕 本周新变化

  • 服务器大换血：从 Python 换成 Node.js + TypeScript，更快更稳定，还自带 API 文档
  • CRDT 同步引擎：全新的数据同步机制，多设备同时操作不会冲突，离线数据不会丢
  • 通知系统：新增专用通知接口，管理端的操作会实时推送到孩子端
  • 战绩回顾页：基于真实数据库，做了一个滚动叙事页面，展示你 22 天的学习数据
  • 测试覆盖率飙升：从 79% 提到 85%，代码质量上了一档

🔧 修了什么 Bug

太多了，挑重点说：

  • 孩子端不会无限重复提交数据了（之前每 5 秒发一次，服务器快被烦死了）
  • 语音播报终于不打架了——不会再出现两句话同时说
  • 作业操作后状态不会再「穿越」回之前
  • TTS 语音缓存常驻内存，不用每次等 Python 冷启动
  • Android APP 更新后自动清缓存，确保最新版
  • Windows 开机自启动终于修好了

📊 项目数据

  • 当前版本：v1.2.18
  • 测试数量：362 项（从 311 涨上来的）
  • 本周提交：100+ 次
  • 新增：Node.js 服务器、CRDT 引擎、通知系统、战绩回顾页
